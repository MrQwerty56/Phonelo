# SCHOOLO — Android APK

Школьный планировщик для Android: расписание на 7 дней, кабинеты, время уроков, расчёт времени подъёма и список домашних заданий. Данные сохраняются локально на телефоне.

## Как получить APK через GitHub

1. Создай новый репозиторий на GitHub, например `schoolo-android`.
2. Загрузи в репозиторий все файлы и папки из этого проекта (включая `.github`).
3. Открой вкладку **Actions** и выбери workflow **Build Android APK**.
4. Нажми **Run workflow**. Также сборка запускается автоматически при push в `main` или `master`.
5. После успешной сборки открой запуск workflow, прокрути до **Artifacts** и скачай **SCHOOLO-APK**.
6. Распакуй ZIP-архив артефакта — внутри будет `SCHOOLO.apk`. Перед установкой на телефоне разреши установку приложений из выбранного источника.

При создании тега вида `v1.0.0` workflow также прикрепит APK к GitHub Release.

## Важно

- GitHub Actions собирает APK в облаке; Android Studio на компьютере не требуется.
- Это debug APK, предназначенный для установки и тестирования. Для публикации в Google Play понадобится отдельная подпись release-сборки.
- Расписание и задания хранятся на устройстве. Облачной синхронизации между устройствами пока нет.
- В текущей версии переключатель уведомлений сохраняет настройку, а разрешение Android запрашивается при первом запуске. Автоматические запланированные уведомления по каждому уроку пока не реализованы.
