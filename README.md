## 📖 О приложении

**SCHOOLO** помогает школьнику не терять время по утрам и не забывать, что и где сегодня по расписанию. Открыл приложение и сразу видишь, какой урок идёт сейчас или будет следующим, в каком он кабинете и во сколько нужно вставать.

Все данные хранятся **только на телефоне**: без регистрации, без аккаунта и без интернета.

## ✨ Возможности

| | Раздел | Что умеет |
|---|---|---|
| 🏠 | **Главная** | Приветствие по времени суток, текущий или следующий урок, счётчик пройденных и оставшихся уроков, время подъёма |
| 🗓 | **Расписание** | Все 7 дней недели, добавление, правка и удаление уроков с кабинетом, временем и учителем |
| ⏰ | **Время подъёма** | Считается само от первого урока: дорога + сборы + завтрак |
| ✅ | **Задания** | Быстрый список домашки, кнопка «Готово» убирает выполненное |
| ⚙️ | **Настройки** | Имя, время на дорогу, сборы, завтрак и напоминание |
| 🌙 | **Тёмная тема** | Мягкий тёмный дизайн с фиолетовыми акцентами |

## 🧭 Как это работает

1. 📝 Заполни расписание на каждый день недели.
2. ⚙️ В настройках укажи, сколько минут занимают дорога, сборы и завтрак.
3. 🏠 На главной экран сам покажет ближайший урок и во сколько нужно проснуться.
4. ✅ Записывай домашние задания и отмечай выполненные.

## 📲 Скачать APK

APK собирается автоматически в **GitHub Actions**:

1. Открой вкладку **Actions** → **Build Android APK**.
2. Выбери последний успешный запуск ✅.
3. В разделе **Artifacts** скачай **SCHOOLO-APK** и распакуй архив.
