# 📚 SCHOOLO — школьный планировщик для Android

**SCHOOLO** — простое тёмное приложение для школьника: расписание на неделю, кабинеты, время уроков, расчёт времени подъёма и список домашних заданий. Все данные хранятся локально на телефоне, интернет не нужен.

## ✨ Возможности

- 🏠 **Главная** — текущий или следующий урок, сколько уроков пройдено и осталось, время подъёма на завтра.
- 🗓 **Расписание** — 7 дней недели, добавление, редактирование и удаление уроков (предмет, кабинет, время, учитель).
- ⏰ **Время подъёма** — считается автоматически от первого урока с учётом дороги, сборов и завтрака.
- ✅ **Домашние задания** — быстрый список дел, отметка «Готово» удаляет задание.
- ⚙️ **Настройки** — имя, время на дорогу, сборы, завтрак, напоминание.
- 🌙 Тёмная тема в фиолетовых тонах.

## 📲 Как получить APK через GitHub

Android Studio на компьютере не нужна — APK собирается в облаке.

1. Создай новый репозиторий на GitHub, например `schoolo-android`.
2. Загрузи в **корень** репозитория всё содержимое проекта, включая скрытую папку `.github`.
   В корне должны лежать: `.github/`, `app/`, `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`.
3. Открой вкладку **Actions** → **Build Android APK** → **Run workflow**.
   Сборка также запускается автоматически при push в `main` или `master`.
4. Дождись зелёной галочки ✅ и открой запуск.
5. Прокрути страницу вниз до **Artifacts** и скачай **SCHOOLO-APK**.
6. Распакуй ZIP — внутри будет `SCHOOLO.apk`.

### Релиз с готовым APK

Создай тег вида `v1.0.0` (**Releases → Draft a new release**). Workflow соберёт APK и прикрепит `SCHOOLO.apk` к релизу, откуда его можно скачать без ZIP.

## 📥 Установка на телефон

1. Перенеси `SCHOOLO.apk` на телефон.
2. Открой файл и разреши установку из этого источника, если Android попросит.
3. Если Play Protect предупреждает, выбери «Всё равно установить» — это debug-сборка.
4. При первом запуске разреши уведомления (Android 13+).

## 🛠 Локальная сборка (необязательно)

Требуется JDK 17 и Android SDK 35.

```bash
gradle assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## ⚠️ Важно

- Это **debug APK** для установки и тестирования. Для публикации в Google Play нужна отдельная подпись release-сборки.
- Расписание и задания хранятся только на устройстве, синхронизации между устройствами нет.
- Переключатель уведомлений пока сохраняет только настройку и запрашивает разрешение Android. Автоматические напоминания перед каждым уроком ещё не реализованы.

## 🔧 Если сборка не запускается

- **«Invalid workflow file»** — проверь отступы в `build-apk.yml` и что файл лежит в `.github/workflows/` в корне репозитория.
- **Красный крестик на шаге Build APK** — открой шаг в логе и найди строку с `error:` или `FAILED`.
- **Нет раздела Artifacts** — сборка не дошла до конца, сначала исправь ошибку выше.
